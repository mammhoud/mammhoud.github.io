# Professional Portfolio

This is my personal professional portfolio, designed and built using **Jekyll** and deployed via **GitHub Pages**.

You can view the live site here: [https://mammhoud.github.io](https://mammhoud.github.io)

The original template was cloned from [`https://github.com/techfolios/template`](https://github.com/techfolios/template).

---

## 🚀 Features

- **Built with Jekyll**: A simple, blog-aware static site generator.
- **Automated with Makefile**: Easily manage build, serve, deploy, and clean tasks.
- **Live Reload Development**: Serve the site locally with instant updates using `jekyll serve --livereload`.
- **HTML Proofing**: Validate the built site using `htmlproofer`.
- **Integrated GitHub Pages Deployment**: Push changes directly to the GitHub Pages branch for seamless updates.

---

## 🛠️ Styling & UI

This portfolio is customized with:
- **Bootstrap**: Quick, responsive layout support.
- **Tailwind CSS**: Utility-first CSS framework for detailed custom styling.
- **FlyonUI & Preline UI**: Additional UI components libraries built on Tailwind CSS.

---

## 📂 Makefile Commands

| Command  | Description |
|----------|-------------|
| `make install` | Install dependencies in a local `vendor/bundle` path. |
| `make build` | Build the site for production. |
| `make serve` | Serve the site locally with live reload. |
| `make clean` | Clean the generated site files. |
| `make deploy` | Push changes to GitHub and trigger deployment. |
| `make update` | Update all project dependencies. |
| `make all` | Install dependencies, build the site, and serve locally. |
| `make check` | Validate the generated site using `htmlproofer`. |
