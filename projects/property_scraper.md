The **Property Website Data Scraper** is an automated Python application developed to scrape real estate listings from well-known property websites.

It continuously extracts property details, tracks historical sales and rental transactions, and stores the data efficiently for future analysis.

### Key Features:
- Automated web scraping of property listings.
- Data matching with existing SQL transaction records.
- Historical tracking for each displayed property.
- Efficient data storage and reporting.

### Technologies Used:
- Python
- Django
- Selenium
- SQL
- Pandas
- Excel

### Project Highlights:
- Successfully ingested live property data and transaction history.
- Enhanced with SQL transaction validation for accurate record-keeping.
- Enabled bulk data export for offline analysis using Excel.
